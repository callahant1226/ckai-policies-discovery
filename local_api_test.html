CKAI API Test (throwaway)

Sends a real request to the CKAI query API and shows the generated answer (llm_response.output_text). Full JSON response is collapsed below each answer — this is still just a smoke test, not the real rendering experience.
Requires proxy_server.py running locally on port 8010 (python3 proxy_server.py) — requests are routed through it to avoid the browser's CORS restrictions, since CKAI doesn't send Access-Control-Allow-Origin headers.
